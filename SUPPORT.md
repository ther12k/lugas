# Support

## Where to get help

- **Bug reports** — open a [GitHub issue](https://github.com/ther12k/lugas/issues/new/choose) using the bug template. Include your Bun version, OS, and a minimal reproduction.
- **Feature proposals** — open an issue with the feature template; describe the problem, the proposed public contract, and whether the capability belongs in core or an optional integration. Large feature pull requests should start with an issue.
- **Documentation gaps** — documentation issues and PRs are welcome; the docs live under [`docs/`](docs/) and the examples under [`examples/`](examples/).
- **Usage questions** — during the beta phase, open a regular GitHub issue tagged as a question.

## Before asking

- Check the [README](README.md) and [`docs/getting-started.md`](docs/getting-started.md).
- Check [`docs/compatibility.md`](docs/compatibility.md) — Lugas requires Bun 1.4.x and is verified against TypeScript 7.0.2.
- Scan [existing issues](https://github.com/ther12k/lugas/issues) for known reports.

## Security vulnerabilities

Do **not** open a public issue for an undisclosed security vulnerability. Report privately via [GitHub Security Advisories](https://github.com/ther12k/lugas/security/advisories/new) per [`SECURITY.md`](SECURITY.md).
