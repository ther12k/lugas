# RFC 9457 — Problem Details for HTTP APIs

**Official source:** https://www.rfc-editor.org/rfc/rfc9457.html  
**Retrieved:** 2026-08-21

RFC 9457 defines a machine-readable Problem Details format for HTTP APIs and obsoletes RFC 7807.

Lugas uses standard members such as `type`, `title`, `status`, `detail`, and `instance`, plus documented extension members such as `code` and `issues`.

## Security reminders

- Problem responses must not expose implementation details merely because the format permits `detail`.
- A `type` URI should be stable and controlled; use `about:blank` until an official domain exists.
- Extension members require stable semantics and bounded serialization.
- HTTP status remains authoritative; the body `status` mirrors it.
