## Architecture decisions

- Standard Schema v1 is supported structurally without a core production runtime dependency (0 runtime dependencies preserved).
- Query decoding is deterministic (single key = string, repeated keys = array) and produces null-prototype objects.
- Request validation is optional per route: undeclared inputs bypass decoding and parsing completely.
- Guard chains execute sequentially before handlers; returning a Response short-circuits execution.
- Validation failures produce RFC 9457 Problem Details (400 for malformed JSON, 415 for unsupported media type, 422 for schema invalid).
- Synchronous routes with sync schemas and sync guards retain a zero-Promise fast path.
