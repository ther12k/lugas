# M1 Gate Review

## Status

**PASS locally — M1 kernel and response contract complete.** M1-001 through M1-018 are merged with evidence; M2 implementation may start after this gate merges.

## Merged issues and commits

M1-001 through M1-018 merged in PRs #129–#146. A post-merge correction (`c206180`) fixed compilation of Lugas descriptors nested inside native method maps after the M1 conformance suite exposed the defect.

## Architecture decisions

- Bun native router remains authoritative; Lugas composes route entries once at startup.
- Native `Response`, `BunFile`, directory, and method-map values remain pass-through values.
- Lugas descriptors compile to native handlers with request/services/params context.
- Sync handlers preserve a non-Promise fast path.
- Thrown descriptor errors are wrapped and redacted before reaching clients.
- Root package exports are available; client/testing subpaths remain deferred to M3/M4.

## Public API changes

M1 root export map now exposes `defineApp`, `defineModule`, `route`, `guard`, `json`, `text`, `empty`, `problem`, `redirect`, and associated types. Package remains private and unpublished.
