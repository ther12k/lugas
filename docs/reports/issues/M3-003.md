## Outcome

Completed. Implemented status-discriminated client outcome extraction in `src/client/types.ts` (`ClientOutcome`, `ClientOutcomes`). Conditional handler returns narrow to exact statuses (e.g. 200 | 204 | 404), async handlers preserve the same union after `Awaited`, guard short-circuit responses merge into the outcome union, and raw unbranded Responses widen conservatively to `{ status: number; body: unknown }` without ever becoming `any`.

## Precision fix (cross-file impact)

Precise response typing was previously erased because `RouteDescriptor.handler` and `.before` were declared with widened concrete signatures (`RouteHandler` returning `Response | Promise<Response>` and `ReadonlyArray<GuardDescriptor<TServices, unknown>>`). To preserve handler/guard response literals for contract extraction:

- `src/core/types.ts` — `RouteDescriptor` gained `TReturn` and `TGuards` generics; `GuardDescriptor`'s handler now returns the precise `TResult` union. Existing `ExtractGuardEnrichment`/`ExtractGuardResponse` extractors already distribute over unions, so M2 semantics are preserved.
- `src/core/route.ts` / `src/core/guard.ts` — factories infer and carry the precise return/guard types into descriptors.
- `tests/types/guard-descriptor.test-d.ts` (M1-005 fixture) — updated to the precise-return annotation with an added `ExtractGuardEnrichment` assertion; primitive-return rejection still enforced.
