## Outcome

Completed. The unified M2-009 problem factory module
(`src/internal/validation-problem.ts`) is now the single canonical source for
validation Problem Details:

- `validate-params.ts` no longer defines its own `createValidationProblem`;
  it imports and re-exports the canonical one for its existing importers
  (`validate-query`, `validate-body`, `validate-headers`).
- `parse-json-body.ts` no longer defines local 415/400 factories; it imports
  them from the canonical module.
- Divergence eliminated: 415 (`UNSUPPORTED_MEDIA_TYPE`) and 400
  (`MALFORMED_JSON`) bodies now include `status` and `source: "body"` — the
  same member set as 422 — verified live through a served app:
  - 415: `{type, title, status: 415, code, source: "body", detail}`
  - 400: `{type, title, status: 400, code, source: "body", detail}`
  - 422: `{type, title, status: 422, code, issues, source}`
- Conformance coverage extended with a live request-path test proving all
  three statuses flow consistently through `defineApp().serve()`.
