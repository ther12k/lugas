## Assumptions

- TypeScript 7 (native) exposes no JS compiler API, so the graph checker uses statement-level parsing with grammar-sound rules instead of a TS AST.
- "Bun-disabled import smoke" is strongest when executed under a foreign engine: standalone Node v24 provides native fetch/Response/Headers/URL without any Bun global; deleting/redefining Bun's global inside Bun itself is impossible (readonly binding verified by probe).
- Tree shaking proof compares a full-surface entry against a single-function entry under identical build settings.
- If Node is unavailable in some environment, the execution smoke skips with a warning while the other three checks still run; CI matrices running this suite are expected to include Node (as this machine does).
