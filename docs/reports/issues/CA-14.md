# CA-14 Evidence Report

Owner review of #414 (2026-09-12), findings 3 and 4: the starter's
startup/RSS figures had harness defects and must be withdrawn pending
remeasurement; the asset mapping lacked CSS coverage; the
LUGAS_REQUIRE_STARTER flag was documented but not enforced.

## 1. Measurement harness repair (scripts/measure.ts) and remeasurement

All three cited defects fixed, plus two more the repair itself surfaced:

- **Timer boundary**: `performance.now()` starts BEFORE spawn; the timer
  closes only on a successful `/api/ready` response (launch → imports →
  init → serving all inside the window). `readyLineMs` (spawn → readiness
  line) recorded as a sub-metric.
- **Process boundary**: direct spawn of the pinned Bun executable
  (`process.execPath`) against `dist-server/main.js` — no `bun run` runner;
  `proc.pid` IS the server whose RSS is sampled.
- **Exit code**: `await proc.exited` retained verbatim (`exitCode`), for
  both profiles (both 0 here — graceful SIGTERM drain).
- **Cleanup**: `finally { proc.kill; await exited }` — failure paths cannot
  leak the child.
- **Workload rigor**: every request must be `res.ok` and its body consumed
  before counting; the request phase is timed separately from the settling
  delays (`requestPhaseMs` vs `settleDelayMs`).
- **Found during repair**: the old workload fetched the shell even in the
  api-only profile and silently accepted its 404 (zero assets counted);
  the workload is now profile-aware.
- **Artifact identity**: report binds to what was actually tested — sha256
  of the installed tarball, server bundle, every frontend output; source
  commit + clean/dirty state; resolved versions (react 19.3.0,
  react-dom 19.3.0, vite 7.3.6, zod 4.6.4, starter typescript 5.9.3);
  bun version + executable path.

**Old artifact marked SUPERSEDED** (`measurements/2026-09-12-api-vs-spa.json`):
status + supersededBy fields name the three invalid metrics (readyMs,
RSS figures, shutdownExit) and the preserving-as-historical intent.

**Remeasured** (`measurements/2026-09-13T005755-api-vs-spa-v2.json`), single
run on the development host, dirty CA-14 checkout recorded in identity:

| Metric (v2, honest) | api-only | api+spa |
|---|---|---|
| launch → readiness line | 95 ms | 92 ms |
| launch → /api/ready 200 | 110 ms | 121 ms |
| idle RSS (server process) | 35.0 MiB | 32.6 MiB |
| RSS after workload (+settle) | 36.0 MiB | 38.4 MiB |
| requests (verified+consumed) | 40 | 120 (shell rounds incl. JS+CSS) |
| request phase | 11 ms | 54 ms |
| exit code (SIGTERM) | 0 | 0 |

The earlier "13 vs 11 ms" and "8.0 vs 7.9 MiB" figures are withdrawn: the
first measured almost nothing (timer opened at the readiness line), the
second sampled the script-runner process. Real launch-to-readiness is
~0.1 s and real server RSS ~33–38 MiB on this host/run — single-run
numbers to establish, per the artifact's note; optimization work targets
these, not the v1 figures.

## 2. CSS / referenced-asset mapping (scripts/build.ts + fixture + tests)

The manifest regeneration now maps EVERY emitted output — entry `file`
plus `css[]` and `assets[]` references (deduped, HTML shell excluded) —
so a stylesheet that exists only as the entry's css reference still gets
an explicit hashed mapping (ADR-0037 object form). Fixture: `src/App.css`
imported by the app; the generated manifest now lists both
`index-*.css` and `index-*.js`; the starter test asserts the stylesheet
serves with `text/css`, the immutable cache header, and the expected
content. 12/12 starter tests green.

## 3. LUGAS_REQUIRE_STARTER enforcement (tests/starter.test.ts)

The gate decision is a pure function (`starterGateDecision({ required,
missing })`) pinned by always-run contract tests: not-built+not-required
→ documented skip; not-built+required → runs with an explicit failure
message; built → always runs. The main suite's first test throws that
message when required-but-not-built. Verified end-to-end: with `dist`
hidden, `LUGAS_REQUIRE_STARTER=1 bun test` exits 1 with "…run: cd
examples/spa-starter && bun run setup && bun run build" (9 failing
tests); restored, 12/12 pass. README updated.
