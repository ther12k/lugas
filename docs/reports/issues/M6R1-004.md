# M6R1-004 Evidence — Snapshot and freeze guard chains at route() creation

## Baseline
- Base commit: 6382faf (main)
- Issue: #259 (M6R1-004)
- Bun/TypeScript: 1.4.0 / 7.0.2, Linux x64

## Outcome
Completed. `route()` now snapshots the caller's `before` array into a frozen
copy at descriptor creation. Descriptor, compiled pipeline, and manifest all
consume the snapshot, so mutating the caller's reference after `defineApp()`
can no longer empty the runtime guard chain or desync manifest metadata.

Note on history: correction evidence attached to bc29ed1 claimed this change
previously; that commit did not touch `src/core/route.ts` (tracked separately
in #260/M6R1-005). This issue delivers the actual source change.

## Security considerations
Closes a security-sensitive immutability gap: a plugin holding the original
array reference could previously disable guards after preparation while the
manifest still advertised them.

## Known limitations / deferred
- Deep-freeze of individual guard descriptors is out of scope (guards are
  already frozen by `guard()`; only the array container was caller-owned).
