## Assumptions

- Declared slot properties are non-readonly in the derived type (the pipeline assigns plain objects post-validation); readonly was tried and removed after the golden probe showed the mismatch.
- Collision semantics: same guard key with different types collapses that property to `never` at compile time — mirrors the runtime collision error without silently shadowing.
- Guard input typing (guards receiving prior enrichments as typed input) is NOT covered here — the issue scope covers handler context output only.
- The old `TContext` escape hatch remains on `RouteDescriptor` for back-compat but defaults to `never` inside `route()` since the derived context supersedes it.
- One legacy test-d assertion (`_syncIsDescriptor`) loosened from exact-generics match to default-generics descriptor-ness because the second generic is now a derived intersection rather than `unknown`.
