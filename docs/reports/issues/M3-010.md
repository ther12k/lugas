## Assumptions

- Ownership/precedence rule (documented in module header): platform options may not carry `method`, `body`, or `headers` at all — their presence is `LUGAS_CLIENT_007` rather than a silent override. This is stricter than precedence-based merging and makes contradictions impossible instead of adjudicated.
- JSON content-type policy: default `application/json` is set only when the caller supplied no content-type; caller-supplied JSON-compatible types (`application/json*`, `application/*+json`, mirroring M2-007's server policy) are preserved verbatim; non-JSON caller content-types with a declared body are a documented `LUGAS_CLIENT_008` conflict.
- `undefined` and `null` declared bodies mean "no body": nothing is sent, no content-type is synthesized — never a literal `"undefined"`.
- Header values must be strings without CR/LF; diagnostics quote only header names, never values, so authorization/cookie secrets cannot leak through error messages.
- Nested `NaN`/`Infinity` inside objects follow native `JSON.stringify` semantics (`null`) — recorded as limitation; top-level non-representable bodies throw `LUGAS_CLIENT_008`.

## Type/runtime/bundle impact

- Canonical method input now covers all five structured slots plus platform `init`; slots stay optional-`undefined` when the route does not declare them.
- Client browser bundle grows by the request builder (~2 KB); zero dependencies beyond platform fetch primitives.

## Security considerations

- Diagnostics are value-free by construction (names only), verified against a planted secret.
- CRLF in header values rejected before `Headers` construction and before dispatch; live test confirms nothing reaches the wire.
- Content-type conflicts surface as client diagnostics instead of mismatched server 415s, preventing accidental plaintext leakage of serialized payloads.

## Known limitations

- Nested non-JSON-safe scalars (`NaN`, `Infinity`) serialize per native `JSON.stringify` as `null`.
- Platform options are validated only for owned-key presence and object shape; exotic `RequestInit` extensions are forwarded verbatim by design.
