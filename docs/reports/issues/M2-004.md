## Outcome

Completed. Implemented deterministic URL query decoding converting URL search parameters into a null-prototype dictionary. Single occurrences decode to strings, repeated keys decode to string arrays in source order, empty keys decode to `""`, and no implicit coercion (numbers, booleans, dates, CSV, JSON) is performed.

- `tests/security/query-object.test.ts` — 4 security tests verifying null-prototype representation, prototype pollution resistance (`__proto__`, `constructor`, `prototype`), and clean object boundary.

## Security considerations

- Returns a null-prototype object (`Object.create(null)`) so `Object.prototype` cannot be polluted by query keys such as `__proto__` or `constructor`.
- Preserves raw string representations so schemas explicitly handle validation and sanitization.
