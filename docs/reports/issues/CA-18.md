# CA-18 Evidence Report

## Baseline

- Base commit: `7e39bbe` (Merge pull request #426 — compatibility matrix fully green)
- Branch: `agent/CA-18-deferred-perf-gate-beta5` / Worktree: `.worktrees/CA-18`
- Bun version: 1.4.0 (x64 Linux)

The beta.5 candidate was otherwise release-ready (27/27 packaging rehearsal,
six-cell compatibility matrix green, zero open P0/P1). The release-mode
performance gate could not be validly executed: the pinned baseline host is
occupied by an unrelated 72 h soak campaign in the sibling `velqu` workspace
(load average ~13), and `docs/performance-gates.md` voids loaded-host
measurements. The owner authorized a recorded deferral (ODR-0020) with the
full gate committed to run post-soak.

## Outcome

1. **`--defer-perf` on the performance checker** (`scripts/check-performance-budget.ts`):
   - Release-mode only; rejected without `--release`.
   - Requires `LUGAS_PERF_DEFERRAL_REF` naming the authorizing owner decision — a deferral without a named decision is rejected.
   - Writes `lugas-release-evidence-v2` with `perfGate: "deferred"`, `deferralRef`, **null** throughput/typecheck/bundle measurements, null environment binding, and the rehearsal tarball hash (fail closed if the rehearsal has not run).
   - Verdict prints `DEFERRED … not passed` — a deferral is never a PASS.
2. **Plan truth table** (`scripts/perf-gate-plan.ts`, `scripts/verify.ts`):
   release + `LUGAS_PERF_DEFERRED=1` → `--release --defer-perf`, regardless of
   archive presence. Development mode unchanged. Deferred-without-release is inert.
3. **Packet builder** (`scripts/release/build-beta-packet.ts`):
   - Derives its mode from the evidence artifact; aborts when invocation env
     (`LUGAS_PERF_DEFERRED`) disagrees with evidence `perfGate`.
   - Deferred mode: benchmark-archive presence checks skipped; measurement
     fields must be **null** (populated measurements in deferred evidence abort);
     `deferralRef` required; tarball/binding checks unchanged.
   - Threads the deferral into the builder-executed verify so the re-executed
     gate runs in the same mode; aborts if the regenerated evidence changes
     mode or `deferralRef`.
   - Generated RELEASE_PACKET.md §4 renders a deferral statement with
     threshold-only rows (no fabricated numbers); executive summary states the
     one recorded deferral; CHECKLIST.md Performance Gate bullet states the
     deferral, the immutability consequence, and the post-soak commitment.
   - Also corrects the stale §8 claim that declarations ship as direct `.ts`
     sources — since CA-17 the distribution ships `dist/*.js` + `dist/*.d.ts`.
4. **ODR-0020** (`docs/owner-decisions/beta5-deferred-performance-gate.md`):
   records the waiver, the owner instruction, the immutability risk
   acknowledgement, the binding post-soak commitment (conditions re-verified
   first; calibration samples and gate result recorded separately; 2,500 ms
   budget unchanged), and owner-executed publication.

Default pipeline unchanged and fail-closed: without the explicit flag and
reference, release mode still fails on missing/stale evidence (pinned by the
existing CA-13 tests, which still pass).
