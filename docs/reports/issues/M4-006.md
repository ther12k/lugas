## Outcome

Completed. `createTestServer(app, options?)` wraps the production `app.serve()` path with test ergonomics: ephemeral port by default, exposed `port`/`url`/native `server`, relative-path `fetch`, and an idempotent async `stop()`/`dispose()` that force-closes connections so fixtures observe released handles. Route/fallback/error/notFound/onError overrides are rejected with a new catalog code before any listener exists.

## Assumptions

- Forbidden option set is an ALLOWLIST (`port`, `hostname`, `development` only) — stricter than enumerating forbidden keys, so future serve options cannot silently bypass test determinism.
- Stop uses `server.stop(true)` (force-close) so "no active handles" is immediately observable; graceful drain semantics belong to M4-008.
- The helper imports nothing from internal compilation modules; its runtime imports are the diagnostics registry plus types — satisfying the spirit of "imports only from lugas/testing" ahead of that subpath's wiring by an integrator.
