## Assumptions

- Canonical methods take `(path)` only in this issue. Structured inputs arrive via M3-008–M3-010; accepting them now without handling would invite silent data loss, so they are deliberately not yet part of the signature.
- Methods return `Promise<Response>`; discriminated outcome parsing is owned by M3-011 (`ClientOutcomesFor` from M3-003/004 remains unused until then).
- "Unsupported method/path cannot silently dispatch" is satisfied by (a) compile-time restriction on canonical methods and (b) strict runtime verb validation on `request`; arbitrary JS-supplied paths to canonical methods are undetectable at runtime by design (compile-time facts and runtime facts stay distinct, architecture rule 8).
- The escape hatch is typed `(method: HttpMethod, path: string)` — closed verb set, open paths — which does not weaken canonical method-specific inference.
- The `_api?: API` phantom introduced in M3-006 was removed now that `API` is genuinely referenced by the method signatures (runtime keys were unchanged by this).

## Implementation

- Each canonical method is an explicitly written property function closing over `send(method, path)`; `send` calls `transport(joinUrl(baseUrl, path), { method })`. No casts are used anywhere in the implementation — contextual typing against `ClientMethod<API, M>` types every arrow exactly.
- `PathsForMethod` intersection with `string` keeps all prior Equal assertions valid while making the result safe for URL joining.
- `request` validates its verb against `CLIENT_HTTP_METHODS` before dispatching and throws a clear diagnostic otherwise.

## Type/runtime/bundle impact

## Security considerations

- Escape hatch rejects unsupported/non-uppercase verbs before any network dispatch.
- No Proxy, no dynamic evaluation, no route metadata inferred from types at runtime.
- Frozen client object prevents post-creation transport or method tampering.

## Known limitations

- Canonical methods accept only `(path)`; structured input fields land in M3-008–M3-010.
- Responses are returned raw; discriminated parsing lands in M3-011.
- Arbitrary paths passed to canonical methods from untyped JavaScript cannot be rejected at runtime (types erased by design).
