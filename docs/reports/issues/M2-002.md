## Security considerations

- WeakSet-based cycle detection prevents infinite recursion or memory exhaustion on hostile recursive issue objects.
- Throwing getters on issue properties are caught and defaulted to safe values.
- Raw input, request payloads, causes, and schema instances are filtered to prevent information disclosure in Problem Details responses.
