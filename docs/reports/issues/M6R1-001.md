## Outcome

Completed. The performance budget gate now fails closed:

- Zero-sample scenarios (archive present, no matching data) → **FAIL** (was: silent skip).
- PASS is only printed when every required scenario either actually compared or all
  missing archives triggered SKIP (pre-benchmark fresh checkout).
- Scenario IDs aligned: `benchmark-plain.ts` now emits `plain-static` and `plain-json`
  matching `m5-accepted.json` baseline keys exactly (was: `/static`, `/json`).
- Results are read from the correct subdirectories for each scenario type:
  plain from `m5-plain/results.json`, validated from `m5-validated/results.json`.
- Gate wired into `verify.ts`: runs when `benchmarks/results/m5-plain/results.json`
  exists; SKIPs on clean checkout; FAILs when archive present but gate fails.

```text
# ✗ plain-static: results archive present but zero samples found
# FAIL: 2 blocking failure(s), 0 alert(s)  [exit 1]

# Correct IDs above threshold → PASS/SKIP
echo '{"results":[{"scenario":"plain-static",...},{"scenario":"plain-json",...}]}' > benchmarks/results/m5-plain/results.json

# ✓ plain-static: 65000 rps ≥ target 60000 rps

# SKIP: no results archive present — run benchmarks to enable the gate (1 scenario(s) skipped)

# Clean checkout (no archive) → verify SKIP
rm benchmarks/results/m5-plain/results.json
bun run verify
# == perf-gate == SKIP: no benchmark results archive  [exit 0]
```
