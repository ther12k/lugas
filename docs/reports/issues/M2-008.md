## Outcome

Completed. Connected the JSON media-type parser to Standard Schema execution, exposing transformed body data to downstream route handlers and guards. Maps unsupported media types (415), malformed JSON (400), and schema validation failures (422) through Problem Details with normalized, redacted issues. Routes without a body schema incur zero body-reading overhead.

- `tests/types/body-validation.test-d.ts` — static type assertions for transformed body output vs undefined.
