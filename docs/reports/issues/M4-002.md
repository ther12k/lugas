## Assumptions

- Method-map expansion: composed entries for descriptor routes are objects keyed by uppercase method (`{ GET: descriptor }`); each child is classified individually, so `{ GET: new Response() }` under a method key records a native row with that explicit method rather than a catch-all.
- Native any-method entries (bare Response/Blob/primitive/function, `{dir}`) record `method: "*"` — the runtime truth that Bun matches every method. `"*"` and lugas `ALL` keys are recorded verbatim; their final serialized representation in the public manifest JSON is deferred to the manifest assembly step and will require the frozen schema's wildcard representation to be settled (flagged as correction-required there if it exceeds additive change).
- Classification mirrors composition's own rules exactly (uppercase-key scan; `handler`+`before` array = descriptor; sole-`dir` = directory), so manifest truth cannot drift from routing truth.
- Ordering: capture preserves declaration order; sorting is a separate explicit step implementing the frozen policy (path then method, code-unit; `*` naturally first).
