## Outcome

## Assumptions

- Codes are frozen API; messages/hints/context keys may evolve. The one exception recorded: `guard(): 'name' must be a non-empty string` is additionally pinned by a golden because downstream suites match it literally.
- Legacy data-only shape `LugasDiagnostic { code, message }` remains exported for path analysis results; new code registry replaces the old string union (`ROUTE_DUPLICATE` → `LUGAS_ROUTES_001`, `ROUTE_UNSUPPORTED` → `_002/_003`, `PATH_INVALID` → `_004`). No external consumers existed for the old strings (verified by repo-wide search).
- Context values are scalar identity facts only — payload/header leakage is prevented by convention here and verified by the existing security suites.
