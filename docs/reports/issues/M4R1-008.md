## Assumptions

Recorded before coding:

1. **ADR-0017 settles the schema divergences** (drafted in this PR for owner review; not silently self-accepted):
   - `routes[].method` values are the seven HTTP verbs **plus `"*"`** for any-method claims — amending the frozen doc's verbs-only restriction that the implementation already contradicted (review P0-4).
   - A bare `route()` descriptor yields exactly **one** `"*"` record (`kind: "lugas"` with its validates/guards), fixing the zero-records bug where non-uppercase keys were skipped.
   - Native taxonomy stays `static | handler | directory`; plain functions are `handler`.
   - Out-of-schema uppercase method keys can never reach a manifest: `defineApp()` fails closed (`LUGAS_ROUTES_002`) before one is exposed.
   - Opaque nested objects under a method key (Bun passes them through raw) record as `native: "static"` passthrough rows rather than being misread as descriptors.
2. **Single interpreter**: manifest records are captured as *facts* at classification time inside `prepareApp()` (new shared `src/internal/route-fact.ts`). Manifest code only orders, assembles, freezes. `captureRouteRecords()` changes input from raw composition entries to prepared facts — merged test updated mechanically to consume `(app as …).prepared.facts`; its assertions (which encode correct v1 truth for its fixture) remain intact.
3. **Composition keeps its validation role** (duplicate rejection across owners) but no longer feeds the manifest. `defineApp()` order becomes compose (validate) → prepare (facts+compile) → manifest (assemble).
4. **`frameworkVersion` becomes a generated build constant** (`src/internal/framework-version.ts`, synced by `scripts/sync-version.ts` reading `package.json`), removing the synchronous filesystem read from `defineApp()`. A repo-context test asserts constant === package.json version so drift fails CI. Wiring the npm script is `package.json` (shared-file) work — recorded below as pending integrator action instead of editing it here.
5. **Golden fixtures**: none exist yet (M4-009 paused). No golden edits are needed; the corrected generator is what M4-009 will later lock.
6. **No public API change**: manifest shape gains no fields; only previously-divergent content is corrected.
