## Assumptions

- "Identity preserved where the platform provides it": injected rejections surface as the identical error object (`toBe`), including `cause` chains; platform abort rejections (`DOMException`, name `AbortError`) are recognized by `name` rather than `instanceof Error` because `DOMException` does not extend `Error` on all runtimes.
- Mid-flight abort is proven twice: a signal-aware injected stub and a real delayed `Bun.serve` endpoint aborted after dispatch.
- Retry absence is proven by invocation counting (exactly one transport call per failing request).
