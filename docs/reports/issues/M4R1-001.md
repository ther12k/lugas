## Assumptions

Recorded before coding:

1. **Error timing moves earlier.** Classification and descriptor compilation shift from serve-time to `defineApp()` time; `LUGAS_ROUTES_002/003` now throw at definition. Verified no existing test asserted these errors fire only at serve time. Codes and messages unchanged; catalog `thrownBy` wording updated.
2. **Merge semantics NOT changed.** Current assembly behavior (later module path entry replaces earlier per-path) is preserved inside the snapshot; per-method merge/collision semantics are owned by M4R1-002.
3. **Snapshot depth is structural.** Root and module route maps are own-key copies at `defineApp()`; entry values remain references. In-place mutation of a single descriptor object is out of scope (services must stay live by contract).
4. **Manifest generation untouched.** `buildManifest(composition)` stays; regenerating from the graph is M4R1-008. Both now derive from state captured at `defineApp()` time.
5. **`SafeServeOptions` semantics preserved**, including `fetch` override and pass-through to `Bun.serve`; `options.routes` continues to be overridden by prepared routes.
6. **Internal-only refactor.** No public export changes (`src/index.ts` untouched). `AppInternals.config` removed from stored internals (unused repo-wide); `LugasAppInstance` unchanged.

### Amendment (recorded after first full-suite run, before further coding)

7. **Compilation captures `services` by reference** — later service mutations remain visible to handlers.
8. **Plain-function path entries pass through to Bun untouched.** Eager classification collided with merged M4-002 evidence (`tests/unit/manifest-routes.test.ts`) whose fixture defines a bare function route. Resolution chosen over editing the foreign fixture: bare functions at path level forward verbatim into the Bun route map — Bun's router accepts them natively (pinned-oracle fact) and the manifest already records them as native `"handler"`, so pass-through reduces composition/runtime divergence today. This deliberately pre-delivers a narrow slice of M4R1-004 scope and is flagged for M4R1-GATE attention; M4R1-004 keeps classifier formalization, method-map-position functions, and Promise-returning fast-path conformance.

## Implementation

- `prepareApp()` copies `{...config.routes}` then overlays module route maps in declaration order (parity with previous assembly), classifies each entry once via `classifyRoute()`, compiles Lugas descriptors once with the resolved `onError` policy applied through `withErrorPolicy()`, freezes the containers it created (compiled map + per-path method maps), and returns a frozen `PreparedApp { bunRoutes, notFound }`. User-owned values (native maps, Response/Blob, descriptors) are never frozen or mutated.
- `serveApp(prepared, options)` wires `Bun.serve({ ...options, routes: prepared.bunRoutes, fetch })`.
- `defineApp()` builds composition → manifest → prepared graph once and stores no reference to user config.
