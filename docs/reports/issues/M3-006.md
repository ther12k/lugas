## Assumptions

- "Normalize trailing slash/base path without losing origin/query semantics" is interpreted as: trailing slashes on the base path are stripped; a base URL that itself carries a query string or fragment is rejected with a diagnostic instead of silently dropping those parts (per-request query belongs to M3-009).
- The default transport resolves the global `fetch` once at client creation (`globalThis.fetch.bind(globalThis)`) to preserve receiver binding; lazy per-call resolution was considered and rejected as unnecessary complexity for this issue.
- `LugasClient<API>` attaches the erased application type via an optional phantom property so the parameter is real at compile time without any runtime presence; method typing lands in M3-007.
- A dedicated browser-environment import proof is owned by M3-014 ("Prove the client export is browser-safe and Bun-free"); this issue provides source-scan and browser-target bundling evidence instead.

## Implementation

- `normalizeBaseUrl` parses `string | URL` via `new URL`, rejects non-http(s) protocols, rejects embedded query/hash, strips trailing slashes from the pathname while keeping origin exact (including port).
- `joinUrl` concatenates origin + basePath + request path with guaranteed leading slash (internal helper exercised for later milestones).
- `createClient` validates config shape, normalizes the base URL, selects injected or global fetch, and returns a frozen `{ baseUrl, fetch }` object. The `API` type parameter is accepted and erased.
