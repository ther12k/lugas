## Security characterization (important)

Standalone-process probe on Bun 1.4.0: a raw throwing route handler returns a 500 whose ~50KB HTML development page **embeds the thrown message and stack** (`token=…` observable in the body). Under the bun:test in-process runner the same throw propagates out of `fetch` instead, so the baseline is recorded as a documented skip with the probe transcript here. Lugas must wrap every compiled handler with `withErrorPolicy` (M1-015 wiring) so thrown values never reach clients verbatim.
