# CA-17 Evidence Report

## Baseline

- Base commit: `df395de` (Merge pull request #423)
- Branch: `agent/CA-17-pretranspiled-esm-distribution` / Worktree: `.worktrees/CA-17`
- Bun version: 1.4.0 (x64 Linux)

Earlier exploratory measurements in CA-16 demonstrated that shipping raw TypeScript sources (`./src/index.ts`) imposed a measurable penalty on direct/unbundled execution (`bun server.ts`):
- Unbundled launch-to-readiness observed ~12 ms lower (47 ms vs 35 ms, ~25% lower) and idle RSS was 1.6 MiB lower (27.1 MiB vs 25.5 MiB). This whole-process difference includes runtime module resolution and initialization—not exclusively TypeScript transformation.
- In matched ahead-of-time bundles (`bun build --target=bun`), both started within measurement noise (~34–36 ms) because Bun performs transpilation ahead of time.

Those exploratory measurements motivated the distribution change. CA-17 establishes the emitted package's build and consumer compatibility; performance of the final candidate requires its own artifact-bound comparison.

This issue implements a production-ready, pre-transpiled ESM distribution that compiles TypeScript sources into ready-to-execute ESM JavaScript (`dist/*.js`) with exact declaration files (`dist/*.d.ts`) while preserving all 5 public export keys and the CLI executable.

## Outcome

1. **Dedicated Declaration Emission Configuration**:
   `tsconfig.dist.json` configures TypeScript's declaration-only emission (`declaration: true`, `emitDeclarationOnly: true`, `rootDir: "src"`, `outDir: "dist"`), avoiding root tsconfig test/benchmark/example inclusions.
2. **Module-Preserving Library Distribution Builder**:
   `scripts/release/build-dist.ts`:
   - Transpiles every source file into module-preserving ESM via `bun build --target=bun --root=src --outdir=dist --no-bundle`.
   - Emits exact `.d.ts` declaration files via `tsc -p tsconfig.dist.json`.
   - Stamps the candidate framework version into runtime constants (`dist/internal/framework-version.js`).
   - Ensures CLI shebang (`#!/usr/bin/env bun`) and executable permissions (`chmod 0755`).
3. **All Five Public Export Keys Preserved**:
   - `.` (`lugas`): `./dist/index.js` (types: `./dist/index.d.ts`)
   - `./client`: `./dist/client/index.js` (types: `./dist/client/index.d.ts`)
   - `./client/browser`: `./build/lugas-client.esm.js` (standalone browser artifact preserved from ADR-0021)
   - `./drizzle`: `./dist/drizzle/index.js` (types: `./dist/drizzle/index.d.ts`)
   - `./testing`: `./dist/testing/index.js` (types: `./dist/testing/index.d.ts`)
   - `bin`: `lugas` -> `./dist/cli/main.js`
4. **Committed-Source Rehearsal Pipeline**:
   `scripts/release/package-beta.ts` extended to compile `dist/` and `build/` inside the clean git-archived staging directory, explicitly passing `sourceRoot` to builders, and asserting all 5 export keys, CLI `--version`, and consumer batteries against the installed tarball (27/27 rehearsal checks passing).
5. **No Release Packet Contamination**:
   Historical published-package attestations and release packet files under `docs/releases/beta/` were preserved byte-for-byte from `origin/main`.

### 4. CI compatibility matrix follow-up (post-merge reruns)

First rerun after adding the build step (run 34746383527, `0b7cfc8`): both Ubuntu cells passed — the missing-build prerequisite was real and is fixed. macOS and Windows cells still failed, with a distinct, pre-existing diagnostic that the earlier typecheck failure had masked:

- **Actual diagnostic**: `tests/static/spa.test.ts` expected `LUGAS_SPA_002` for a navigation overlapping an `assets.dirs` mount on every platform, and constructed an `assets.dirs` app at describe-collection time. On non-Linux, `compileAssets` deliberately fails closed first with `LUGAS_ASSET_004` (`assets.dirs` requires Linux openat2(RESOLVE_IN_ROOT); ADR-0018 amendment), so the cells received `LUGAS_ASSET_004`. The SPA hosting test file (ADR-0037) was authored without the platform guards every other static suite uses (`test.skipIf(process.platform !== "linux")` in `assets-config.test.ts`, `assets.test.ts`, `raw-request.test.ts`, `colorjoy-migration.test.ts`).
- **Fix**: `tests/static/spa.test.ts` now follows the established suite pattern — the dirs-mount app carries the mount only on Linux (the plain-miss test runs everywhere; the asset-owned-prefix test keeps its Linux-only early return), and the dirs-overlap assertion expects `LUGAS_SPA_002` on Linux and the documented `LUGAS_ASSET_004` platform gate elsewhere. Linux assertions are unchanged; no runtime code changed.

## Security considerations

- Shipped tarball contains pre-transpiled `.js` and `.d.ts` files only; source TypeScript files, tests, benchmarks, and worktrees are excluded.
- CLI executable is stamped with `#!/usr/bin/env bun` and explicit `0755` permissions.
- Zero production dependencies declared or shipped.

## Known limitations

- Pre-transpiled ESM improves unbundled execution (`bun server.ts`); applications bundled with `bun build --target=bun` transpile ahead-of-time regardless of package distribution format.

## Deferred work
