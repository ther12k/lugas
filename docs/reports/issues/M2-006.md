## Security considerations

- Sensitive headers (`authorization`, `cookie`, `set-cookie`, `x-api-key`, `apikey`, `x-auth-token`) are sanitized during failure normalization so raw tokens and session secrets are never reflected in client-facing 422 Problem Details responses.
- Header projection uses null-prototype objects to defend against prototype pollution from custom headers.
