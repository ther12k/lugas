## Outcome

The ADR-0019 budget policy (as amended) is implemented and pinned:

- **Selection and clamping:** `resolveEffectiveBudget()` implements `routeOverride ?? applicationDefault`, then `min(serverCeiling, selected)`. An override relaxes the default, never the ceiling. Exported for direct unit assertion.
- **Configuration surface:** `defineApp({ bodyBudget })` (application default) and `route({ budget })` (override); positive integers enforced at definition (`LUGAS_BODY_001`).
- **Startup rejection:** budgets above an explicitly configured `maxRequestBodySize` fail at `serve()` with `LUGAS_BODY_003` naming the offending budget (application default and/or route budgets; all collected at compile time). With no explicit ceiling, Bun's runtime default governs and budgets enforce as configured — clamping against an unknown ceiling is not claimed (recorded interpretation per ODR-0006 §3).
- **Framework-parsed enforcement:** bounded consumption in `parseJsonBody(request, budget)` — a `Content-Length` above the budget rejects without reading the stream; chunked bodies are counted byte-by-byte and all further budgeted reads stop at overflow (`reader.cancel()`). Rejection is a `413` **Problem Details** response (`BODY_BUDGET_EXCEEDED`, `application/problem+json`) produced before schema validation and handler execution.
- **Raw-stream narrower form (accepted amendment, ODR-0006 §2):** `budget` on a route without a declared `body` schema is rejected at `defineApp()` with `LUGAS_BODY_002` naming the route — never a silently inert budget.
- **Dual-threshold evidence:** with `maxRequestBodySize: 100_000` and `budget: 1_000`, a 2 kB body produces the Lugas `413` problem envelope while a 150 kB body produces the pinned bare transport `413` (empty body) — both observed in one server, envelopes asserted distinct.
- **Compatibility:** no budget configuration leaves the byte-level behavior identical to the M7-002 pin (bare transport 413; inclusive boundary), regression-tested.

## Security considerations

- Budget rejections reflect no payload content; the problem document carries only the stable code/status.
- The budget gate sits before schema validation and guards, so oversized payloads are never parsed or reflected.
- No second transport counting layer for the ceiling itself: Bun retains transport authority; the Lugas budget is enforced during the framework's own bounded read of declared-body routes only.

## Known limitations / Not exercised

- Per the accepted narrower form, raw-stream (pass-through) routes do not accept budgets; applications needing budgeted raw consumption must consume the stream themselves.
- Enforcement covers framework-parsed routes; native route values remain outside the pipeline (documented boundary).
