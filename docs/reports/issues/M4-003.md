## Assumptions

- "Declared" means the descriptor slot is present (`!== undefined`) — validator identity/properties are never inspected, per ADR-0014.
- Guard names are recorded verbatim in declaration order (= execution order per M2 sequential execution); duplicate names within a chain are recorded as-is since they remain distinguishable at runtime by instance, and module-name duplicates already throw at startup.
- Startup validation ownership unchanged: invalid guard identities still throw from `guard()` itself; this issue adds no new error surface.
- Native rows emit empty arrays rather than omitting fields so every row satisfies the frozen v1 shape uniformly.
