# M6R1-011 Evidence — Shared path-syntax validation for defineApp and defineModule

## Baseline
- Base commit: `563aed1` (main, M6R1-007 merged)
- Issue: #266 (M6R1-011)
- Bun/TypeScript: 1.4.0 / 7.0.2, Linux x64

## Outcome

Completed. Route-path syntax validation now has exactly one implementation:

- New `assertValidRoutePath(path, owner)` in `src/internal/path.ts` wraps the
  canonical `analyzePath()`; failures throw the stable `LUGAS_ROUTES_004`
  LugasDiagnosticError with hint and `{ path }` context — never a plain
  `Error` with the code embedded in its message.
- `defineApp()` (src/core/app.ts): ~25-line inline duplicate validator
  replaced with the shared call.
- `defineModule()` (src/core/module.ts): previously validated only entry
  shape/duplicates, no path syntax at all; now validates every path key with
  the shared validator before duplicate detection.
